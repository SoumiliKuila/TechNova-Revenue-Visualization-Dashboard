📊 TechNova Revenue Visualization Dashboard

A simple and interactive Revenue Visualization Dashboard built using HTML, CSS, JavaScript, and Chart.js.

This mini-project was created as part of a data visualization task for TechNova, where monthly revenue, expenses, and profit data are represented using different types of charts.

🚀 Project Overview

The dashboard visualizes TechNova's monthly financial performance from January to June.

It includes three different visualizations:

- 📈 Line Chart – Compares Revenue, Expenses, and Profit.
- 📊 Bar Chart – Shows monthly Revenue.
- 🥧 Pie Chart – Displays the distribution of June revenue.

The project demonstrates how Chart.js can be used to convert numerical business data into easy-to-understand visualizations.

🛠️ Technologies Used

- HTML5 – Structure of the dashboard
- CSS3 – Styling and layout
- JavaScript – Data handling and chart creation
- Chart.js – Data visualization library

📌 Features

1. Revenue, Expenses & Profit Line Chart

The line chart displays monthly:

- Revenue
- Expenses
- Profit

2. Revenue Bar Chart

The bar chart represents monthly revenue from January to June, making it easy to compare revenue across different months.

3. June Revenue Distribution

The pie chart represents the distribution of June revenue:

- Reinvestment – 40%
- Salary – 35%
- Miscellaneous – 25%

💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any modern web browser.
4. The dashboard will display the three charts.

The project uses Chart.js through a CDN, so an internet connection is required for the Chart.js library to load.
